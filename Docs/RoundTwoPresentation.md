# 2회차 관 연출

InGame 씬의 InGameCore에 `RoundTwoCoffinPresentation`을 연결했습니다. 다른 회차의 연출은 변경하지 않습니다.

- Quest 8 / Target 4 / Round 2: 발생 시각은 기존 데이터 테이블을 따릅니다. 현재 225000ms(기본 시간 배율에서 23:30)이며, 시간 값 변경은 사용자가 별도로 진행합니다.
- 관의 발생/복구는 기존 데이터와 AnomalyTargetAdapter가 처리합니다. 복구는 즉시이며 별도 닫힘 애니메이션은 없습니다.
- MissionOpened에서 관 내부 임시 안광(흰색 구체 두 개)을 켭니다. 최종 눈 아트는 아닙니다.
- MissionResolved에서 안광을 끄고 CreepyGirl_Animated를 현재 카메라의 수평 반대 방향 2m에 생성합니다. 생성 후 플레이어를 따라가지 않습니다.
- 중앙 범위·거리·벽 가림을 모두 통과하면 WASD/시점/상호작용을 1초 제한합니다. 귀신을 보지 않으면 경직하지 않습니다.
- 경직은 한 번만 적용합니다. 1초 경직 종료 후 조작을 풀고, 추가 2초 뒤 귀신을 즉시 숨깁니다(인지부터 약 3초). 일시정지/포커스 해제 중에는 타이머도 멈춥니다. 회차 초기화/게임 종료/컴포넌트 비활성화 시 숨기고 이 연출의 입력 잠금만 해제합니다.
- 연출 사운드는 없습니다. 공통 복구 홀드 사운드는 기존대로 유지합니다.

## Inspector

InGameCore의 Round Two Coffin Presentation에서 Spawn Distance, Ghost Height, Facing Offset, Viewport Half Size, Recognition Distance, Input Block Duration, Disappear Delay After Block, Eyes Offset을 조정합니다.

뒤쪽이 벽으로 막히거나 바닥/설 공간이 없으면 경고를 출력하고 생성을 생략합니다. 입관실의 안전한 위치에 빈 오브젝트를 배치해 Fallback Spawn에 연결하면 대체 위치도 검사합니다. 대체 위치가 벽 너머이면 사용하지 않습니다.

안광 위치와 모델 방향은 실제 맵에서 확인해야 합니다. `Eyes Offset`은 닫힌 뚜껑 Visual 중심에 더하는 월드 좌표(m)입니다.

## 플레이 확인

1. 저장된 InGame 씬을 다시 로드하고 Play.
2. InGameCore에 실행 중 추가된 Game Session Host에서 Test Round Id=2. 컴포넌트 메뉴의 `테스트/지정 회차 시작` 실행.
3. 다음 일정으로 23:30 도달 → CCTV 확인 → 현장 순찰 시작.
4. 관 사건 발생/안광을 확인. 나중에 테이블의 발생 시각을 변경하면 변경된 일정까지 진행합니다.
5. 관을 2초 홀드해 해결: 즉시 원상복구, 안광 꺼짐, 뒤쪽 귀신 생성 로그 확인.
6. 뒤돌기 전에는 이동 가능. 귀신을 화면 중앙에서 보면 1초 이동/시점 제한 후 조작 복귀. 그때부터 추가 2초 후 귀신이 사라지는지 확인.
7. 벽 뒤/설정 거리 밖/화면 가장자리에서는 경직하지 않는지 확인. 다시 봐도 두 번째 경직이 없어야 합니다.
8. 경직 도중 Esc 일시정지 후 재개해 남은 경직 시간이 이어지는지 확인. 회차 재시작하면 귀신/안광/입력 잠금이 초기화되어야 합니다.

## 책임과 검증 범위

Bootstrapper가 기존 데이터 대상과 연출 의존성을 주입하고, 연출은 GameSessionHost.Changed 결과 이벤트를 소비합니다. 미션 규칙은 수정하지 않습니다. PlayerController의 소유자별 잠금은 세션 허용 여부와 함께 검사하므로 일시정지/다른 잠금을 강제로 해제하지 않습니다.

귀신·안광은 한 번 생성해 재사용합니다. 시야 Raycast는 발견 대기 중 기본 20Hz, 중앙/거리 조건 통과 시에만 수행합니다. 이 연출은 로컬 표현이며 네트워크 권한/스폰 동기화는 구현하지 않습니다.

C# 참조 컴파일 통과. Unity 플레이/렌더링 검증은 사용자가 수행합니다. 코어 자동 검증은 NuGet 설정 접근 권한을 얻지 못해 실행하지 못했습니다.
